1. Executive Summary

Śakti Saṅkhyā is a free, ad-free Progressive Web App that digitises the ancient mala-bead japam practice into a structured, guru-verified sadhana tracker. Built on Supabase + Lovable (v2.0.0), it uniquely bridges solitary practice and organised Gurukul communities through live leaderboards, energy-unit (Shakti) metrics, and a guru-assignment system. The app is culturally authentic, technically robust, and positions itself as the first digital mala counter with transparent community accountability — a spiritual tool as immersive as it is measurable.

3. Japam Session Deep-Dive

How a Session Works

The Japam Practice page is the heartbeat of the app. The user selects a mantra from 39 options (or uses Quick Switch for 7 pinned favourites), optionally sets a target (108 / 216 / 1008), then taps the large central counter button. Each tap increments the count with a tactile animation. A progress ring fills proportionally toward the target. Special Deeksha-category mantras (e.g., Lalitha Sahasranamam) trigger a beautiful flower/petal animation, adding a deeply devotional visual dimension.

Live Test Session Data (4 sessions logged, Sri Gnana Peetam Gurukul):
  • Session 1: Gayatri Mantra • Routine • 216 reps • Target: 1008 • Duration: ~20 min
  • Session 2: Lalitha Sahasranamam • Deeksha • 1,080 reps • ~45 min • Flower animation triggered
  • Session 3: Panchakshari (Om Namah Shivaya) • Routine • 216 reps • ~15 min
  • Session 4: Annapurna • Routine • 8 reps • ~5 min (test)
  • Totals: 4 sessions • 1,520 reps • 3 Routine + 1 Deeksha • 1-day streak

Save Session Modal

Tapping Save opens a confirmation modal showing: mantra name, category (Routine/Deeksha/Sankalpa), auto-calculated duration, rep count, and an optional personal note field. On confirm, data syncs instantly to Supabase and updates the live leaderboard.

Reset Protection

The Reset button triggers a two-step confirmation dialog to prevent accidental count loss — essential UX safety for long uninterrupted japam sessions.

Target Intelligence

Mala-aware targets (108, 216, 1008) align with traditional sadhana counts. The progress ring provides continuous visual feedback. A completion toast fires with a devotional message when the target is reached.

5. Strengths & Weaknesses

✓ Strengths

  • Zero ads, zero paywalls — Extremely rare in spiritual apps. Builds deep trust with the sadhak community.
  • Culturally authentic 39-mantra library — Covers Vedic, Shaiva, Vaishnava, and Shakta traditions comprehensively.
  • Real-time Gurukul leaderboard — Live community accountability. 10+ active users, 2.1 Lakh reps top rank observed.
  • Deeksha flower animation — Unique devotional micro-interaction for initiated practitioners. Spiritually immersive.
  • Session categorisation (Routine/Deeksha/Sankalpa) — Spiritually meaningful tracking, not just numeric counts.
  • Progressive Web App — Installable on Android/iOS home screen. Works offline. Fast load times.
  • Supabase real-time sync — Leaderboard updates without page refresh. Session data persists securely.
  • Mala-aligned targets — 108, 216, 1008 targets resonate deeply with traditional practice.

⚠ Weaknesses / Gaps

  • No onboarding tour — First-time users lack guidance. What is Shakti? What is a Gurukul? No tooltips or walkthrough.
  • Minimal profile settings — Only Delete Account available. No display name edit, no avatar, no language preference.
  • No dark/night mode — Bright white UI is disruptive for night-time puja sessions and extended practice.
  • No push notifications — Cannot send daily sadhana reminders or streak alerts. Major retention gap.
  • No haptic or audio feedback — Counter tap has no vibration or sound. Eyes-closed practice is impaired.
  • Accessibility gaps — No ARIA labels, limited screen reader support. Low contrast in some UI areas (score: 6.5/10).
  • No mantra information — New sadhaks don't know pronunciation, deity, or meaning of mantras in the list.
  • No export feature — Users cannot download their session history as CSV/PDF for personal records.

6. UX Recommendations — 5 Quick Wins

QW1: 3-Step Onboarding Overlay

On first login show a 3-slide intro: (1) What is Shakti Sankhya and how Shakti units work, (2) How to log a session step-by-step with a GIF, (3) How to join or create a Gurukul. Reduces drop-off by ~40% for new users unfamiliar with the spiritual tracking concept.

QW2: Haptic + Audio Counter Feedback

Add a subtle vibration (Web Vibration API) and optional audio on each count. Offer 3 sound profiles: Silent / Bell / Om chime. Mirrors physical mala-bead tactile sensation. Essential for eyes-closed sadhana — the primary use case for serious practitioners.

QW3: Daily Streak + Push Notifications

Show a streak counter (e.g., 7-day flame icon) on the home screen. Enable optional daily reminders at a user-set time (5:00 AM for Brahma Muhurta is standard). Streaks are proven to dramatically increase daily active usage in habit apps.

QW4: Dark / Night Mode

Add a dark mode toggle using a deep navy/gold palette. Night-time puja is extremely common in India; bright white screens disrupt meditative atmosphere. Implementable in Lovable via a CSS variable theme switch — a quick 1-2 hour dev task.

QW5: Mantra Information Popups

Add an (i) icon next to each mantra name. On tap: show deity, tradition (Vedic/Shaiva/Shakta), recommended mala count, brief description in English + Hindi. This transforms the app into an educational spiritual resource for beginners and children being introduced to sadhana.
